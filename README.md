# OLX CLONE

OLX-inspired classifieds learning app built with React and Firebase, with account screens, listings, and item detail pages.

## Project scope

This is a learning recreation inspired by OLX. Configure a Firebase project for the authentication, database, and storage calls used by the app. It is not an official OLX product.

## Run locally

Install Node.js and the package manager used below. Run each command block from the repository root; separate frontend/backend processes use separate terminals.

Root application:

```sh
npm install
npm run start
```

Other package scripts: `npm run build`, `npm run test`.
